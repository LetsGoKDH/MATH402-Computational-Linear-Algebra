Definitions

Orthogonality errors: ||U^T*U - I||_F and ||V^T*V - I||_F.

Interpretation
Both cases agree numerically with the theoretical SVD. The errors are consistent with floating-point roundoff.
An exact radical expression is evaluated numerically for comparison; exact equality with == is not required.
Paired column sign changes in U and V do not change U*Sigma*V^T.
The largest orthogonality error is about 1e-13 for n=12; this is still small.
These checks validate the two assignment matrices only, not every possible input matrix.
Recomputing errors from the rounded entries in a saved result file can give larger errors.
